## Требования к каждому снимку

Без этих трёх пунктов скриншот бесполезен, потому что я не могу его «покрутить», как живую таблицу:

1. **Виден диапазон дат.** Он в правом верхнем углу отчёта. Не обрезайте верх.
2. **Видны заголовки колонок.** Мне нужны Clicks, Impressions, CTR, Position (для GSC) и Sessions, Users, Engagement rate, Key events (для GA4).
3. **Таблица уже отсортирована и отфильтрована.** Сортировать и накладывать фильтры нужно ДО снимка. Если таблица не отсортирована, данные есть, но я буду угадывать приоритеты.

Дополнительно: лучше full-page скриншот или 2 снимка с прокруткой, чем узкое окно на 10 строк. Не обрезайте итоговую строку с суммами вверху отчёта.

## Чего я не смогу сделать со скриншотом

- Пересортировать или отфильтровать таблицу за вас.
- Прочитать очень мелкие цифры (тогда попрошу повторить крупнее).
- Получить точные значения, если колонка CTR скрыта под многоточием.

HTML-дампы, скриншоты кода и выгрузки в других форматах не нужны.

## Приоритет 1. GSC, Search results, вкладка Queries

Это главный источник для бенчмарков по категориям.

- **Путь:** Search Console → Эффективность → вкладка «Запросы».
- **Период:** последние 3 месяца (примерно 10 июля — 9 октября 2026).
- **Сортировка:** Clicks, по убыванию.
- **Что должно попасть:** первые 100 запросов, то есть 2–3 снимка с прокруткой.
- **Колонки:** Query, Clicks, Impressions, CTR, Position.
- **Отдельно:** строка с общими суммами вверху отчёта.

## Приоритет 2. GSC, Search results, вкладка Pages

Это обновляет таблицу «Top 28 posts» в baseline и открывает новые категории.

- **Путь:** тот же отчёт → вкладка «Страницы».
- **Период:** последние 3 месяца.
- **Сортировка:** Clicks, по убыванию.
- **Что должно попасть:** первые 50 страниц, то есть 2 снимка.
- **Колонки:** Page, Clicks, Impressions, CTR, Position.

## Приоритет 3. GA4, два отчёта

Ключ к стратегии: в `.ai/content-strategy.md` зафиксировано, что большая часть трафика идёт НЕ из Google.

**3.1. Привлечение трафика**
- **Путь:** Отчёты → Привлечение → Привлечение трафика.
- **Измерение:** Session primary channel group.
- **Период:** последние 3 месяца.
- **Метрики:** Sessions, Engaged sessions, Engagement rate, Key events.
- **Отдельно, важно:** тот же отчёт, но измерение Session source/medium. Нужно увидеть источники вида chatgpt, perplexity, claude, copilot и подобные, это AI-трафик.

**3.2. Страницы и экраны**
- **Путь:** Отчёты → Взаимодействие → Страницы и экраны.
- **Период:** последние 3 месяца.
- **Сортировка:** Views, по убыванию.
- **Колонки:** Page path, Views, Users, Average engagement time.

## Приоритет 4. GSC, сравнение периодов (эффект Wave 1)

Показывает, сработали ли правки заголовков в мае 2026.

- **Путь:** Эффективность → кнопка «Сравнить».
- **Сравнение:** последние 3 месяца против предыдущего периода (то есть июль–сентябрь 2026 против апрель–июнь 2026).
- **Что нужно:** вкладка Queries, сортировка по изменению Clicks, а также 2–3 запроса из списка Wave 1 (например `tabs ui design`, `tab ui design`, `notifications ui design`).
- **Плюс:** общий график Clicks и Impressions за период с видимой дельтой в процентах.

## Приоритет 5. Техника и общее состояние

Нужно для блока «Технический SEO» и оценки индексации.

- **Индексирование → Страницы.** Сколько проиндексировано, сколько нет, и причины.
- **Индексирование → Карты сайта.** Карта отправлена и обработана, число обнаруженных URL.
- **Опыт → Основные веб-показатели.** Mobile и Desktop отдельно.
- **Эффективность → вкладка «Устройства»** (если в вашем интерфейсе она доступна). CTR на мобильных обычно ниже, это влияет на выводы.

## Отдельно, для rescue-кластеров

По трём проблемным кластерам нужны срезы по конкретным URL, чтобы измерить, помогла ли переработка:

- **tabs:** filter = страница `/blog/tabs-ui-design`, вкладка Queries.
- **notifications:** filter = `/blog/notifications-ui-design`, вкладка Queries.
- **guest posts:** filter по каждой из пяти страниц кластера, вкладка Queries.

Путь: GSC → Эффективность → кнопка фильтра «Страницы» → вставить URL → вкладка Queries. Период последние 3 месяца.
