## Итог одной строкой

Гипотеза «Wave 1 испортила заголовки» **не подтвердилась**. Настоящая причина —
кластерное падение позиций по всем компонентным постам одновременно. Правки
title/description тут почти ни при чём; это внешнее изменение ранжирования.

## Что из этого следует

### 1. Позиция упала почти у всех — это главный факт

14 из 15 постов потеряли позицию, в среднем на 1.7 пункта. Худшие:
carousel (−5.4), button (−4.1), dropdown (−2.8), pagination (−2.5),
slider (−2.5), notifications (−2.4), settings (−2.3).

Падение позиции на 1.5-4 пункта само по себе объясняет падение CTR:
на позиции 8-11 кликают хуже, чем на 7-8. То есть CTR здесь — следствие,
а не причина. Правка заголовков не могла «сломать позицию» — заголовки на
ранжирование влияют слабо, а тут просели все посты разом.

### 2. Пять постов всё равно выросли по кликам

tabs (+440), pagination (+90), toggle (+37), settings (+25), checkbox (+18)
прибавили клики несмотря на падение позиции, потому что выросли показы.
Это говорит, что спрос по этим темам растёт, и посты его частично ловят.

### 3. empty-state — отдельная аномалия, требует проверки

Показы выросли вдвое (40 518 → 85 421), а CTR упал втрое (0.21% → 0.08%).
Позиция при этом не изменилась (7.63 → 7.61). То есть пост стал чаще
показываться, но почти не кликается. Это не похоже на падение ранжирования —
скорее показы идут по нерелевантным запросам, либо сниппет не совпадает
с интентом. Нужна ручная проверка: открыть в GSC запросы именно этого URL.

### 4. Кластер просел целоком, а новые посты выросли

Пока компонентный кластер терял позиции, новые посты (claymorphism,
liquid glass vs glassmorphism, data table, retro-brutalist) росли с нуля.
Это признак смены предпочтений выдачи в пользу свежего контента, а не
результат наших правок. Урок: «пачкой править заголовки» действительно
нельзя, но не потому что это вредит, а потому что это не влияет на
позицию — усилия надо направлять в качество и свежесть.

## Что это значит для решения «откатывать или усиливать»

| Категория | Посты | Решение |
|---|---|---|
| Растут, не трогать | tabs, pagination, toggle, settings, checkbox | Оставить как есть |
| Просели по позиции, но спрос есть | dropdown, filter, chip, tooltip, breadcrumbs, slider | Усиливать содержимое, не заголовки |
| Просели сильно | notifications, carousel, button | Проверить каннибализацию и качество, возможно объединить |
| Аномалия сниппета | empty-state | Сначала разобрать запросы в GSC |
| Пограничный | button-group-guide (не в Wave 1: 347 → 270) | Взять в работу вместе с button |

Откатывать заголовки **не нужно нигде**: доказательств вреда нет, а пять
постов с теми же правками выросли.

## Что делать дальше (предложение, не действие)

1. По **empty-state**: выгрузить запросы этого URL из GSC и понять, за счёт
   чего удвоились показы при нулевом CTR.
2. По **notifications, carousel, button**: проверить каннибализацию — рядом
   есть button-group-guide и другие посты той же темы, возможно они делят
   один интент.
3. По **просевшим по позиции**: не трогать заголовки, а обновить содержимое
   (свежесть, полнота, FAQ) — это ложится на Wave 4 (rescue-планы уже есть
   в `.ai/`).
4. **Вывод для протокола**: следующий батч правок заголовков делаем только
   там, где низкий CTR при стабильной позиции, а не там, где упала позиция.

## Чего этот разбор не доказывает

Мы не знаем точную дату падения позиций. Возможно, оно случилось до Wave 1
или одновременно с апдейтом Google, а не из-за наших правок. Чтобы это
разделить, нужен дневной график позиций по 2-3 постам в GSC (вкладка
«Эффективность» → даты). Это отделнная проверка на стороне владельца.
